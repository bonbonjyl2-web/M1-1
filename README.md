### 2.2 결측치 및 이상치 정제 전후 영향 수치 [평가항목 #9]

* **결측치 (Missing Values)**: 
  * **전/후 수치**: 정제 전 **0건 (0.0%)** $\rightarrow$ 정제 후 **0건 (0.0%)** (원본 데이터 무결성 확인)
* **이상치 (IQR Clipping)**: 
  * **기준**: $Q1(180) - 1.5 \times IQR(138.5) = -27.75$ (하한), $Q3(318.5) + 1.5 \times IQR(138.5) = 526.25$ (상한)
  * **전/후 수치**: 상/하한선 이탈 관측치 **0건 (0.0%)**
  * **영향 분석**: 전체 144개 데이터가 IQR 정상 범위 내 존재하여 수치 훼손 없이 원본 100% 활용.

## 3. 시계열 분해 및 요소별 정량적 분산 기여율 [평가항목 #12]

시계열 변동성을 수학적으로 검증하기 위해 로그 변환 후 각 성분의 분산 기여율(Variance Share)을 산출함.

$$\text{Variance Share} = \frac{\text{Var}(\text{Component})}{\text{Var}(\text{Total Log Series})} \times 100$$

| 시계열 구성 요소 | 분산 (Variance) | 분산 기여율 (%) | 정량적 의미 해석 |
| :--- | :---: | :---: | :--- |
| **장기 추세 (Trend)** | `0.1184` | **85.30%** | 전체 승객 변동의 약 **85.3%**가 우상향 성장 추세에 의해 설명됨 (압도적 영향력). |
| **계절성 (Seasonality)** | `0.0178` | **12.82%** | 매년 반복되는 여름 성수기 및 11월 비수기 등 계절 패턴이 **12.8%** 설명. |
| **잔차/노이즈 (Residual)** | `0.0026` | **1.88%** | 외부 우발 요인으로 인한 무작위 오차는 **1.88%** 수준에 불과하여 예측 용이성 입증. |
